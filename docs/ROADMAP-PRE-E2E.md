# Pre-E2E hardening roadmap

Этот документ фиксирует задачи, которые можно безопасно выполнять без доступа к реальному тестовому ПК.

## Приоритет 1 — достоверность диагностики

- Не считать отсутствие телеметрии признаком здоровья.
- Отдельно показывать полноту/coverage диагностики.
- Не давать статус `OK`, если критически важные секции не собраны.
- Для событий Windows учитывать повторяемость Provider/Event ID, а не только абсолютное число Error/Critical.

## Приоритет 2 — тестируемость

- Self-test на полностью заполненный healthy dataset.
- Self-test на missing telemetry / degraded coverage.
- Self-test на устойчивую нагрузку и пороги score/status.
- Self-test на noisy, но нерепетитивные Windows events.

## Приоритет 3 — эксплуатация

- Версия приложения и build metadata в отчёте.
- Явная маркировка того, какие данные были недоступны.
- Сохранение текущего безопасного allow-list remediation.

E2E на реальном Windows 11 остаётся обязательным gate перед расширением remediation и перед корпоративным rollout.
