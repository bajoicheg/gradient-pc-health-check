# 0.5.0 — Common workstation problems

## Product scope

Adds the opt-in common-problems window and Windows-tools menu: network/IP/DNS configuration, installed printer/default/offline state, Spooler status and PnP error codes. Existing performance/storage diagnostics and controlled remediation remain in the main window. The additional window has its own evidence/status results, not a hidden extension to the main score.

Read-only collection does not make application-originated DNS/ping/HTTP probes. Windows providers may have their own network behavior. The printing query reads configuration/state, not job document names/content. No driver installation, service restart, job cancellation or corporate network/security setting changes are implemented.

The DNS button is a separate confirmed action using the existing `FlushDns` implementation. Its rescan re-reads configuration only; the user must still retry the affected resource. Settings shortcuts are navigation, not repairs. Exports may contain sensitive device/network names and must not be published unreviewed.

## Automated regression coverage

36 synthetic cases cover collection failures, inactive interfaces, APIPA/link-local/IPv6-only/multiple NICs, configured versus missing DNS, printer/default/unknown state, stopped Spooler, actionable PnP codes and disabled/disconnected devices. Presentation checks cover the fixed Settings URI list, HTML encoding, JSON previous/current envelopes and menu layout. Existing product and worker-negative self-tests remain enabled.

Test-first RED run: Windows EXE 34618719822 built successfully with 0 compiler warnings/errors, passed the previous 19-case guidance and 22-case completeness suites, then produced 4/36 passes on the empty new assessment contract (exit 111). This confirmed that the new behavior was not already present. Final GREEN and release status must be taken from the exact final PR/main runs, not from this RED run.

## Required pilot acceptance

- Normal-user Windows 11 startup: main window still scans and the new menu does not overlap it; check 100/150/200% DPI and keyboard navigation.
- IPv4-only, IPv6-only, VPN plus another NIC, APIPA secondary NIC, no configured DNS, offline workstation: inspect facts rather than claiming internet reachability.
- Installed/default/offline printer, unknown driver status, no printer, GPO-disabled Spooler and denied WMI: distinguish INFO/WARN/UNKNOWN. Confirm actual printing separately.
- Present PnP codes 10/14/28/31/43 versus disabled/disconnected 22/24/45. Do not enable or install anything automatically.
- Cancel and close during WMI collection; reopening must not create concurrent provider work. WMI/provider cancellation is cooperative, not a guaranteed hard timeout.
- Copy and local export: Unicode, long names and HTML-like device names are preserved as text; previous/current timestamps are distinct and missing data is visible.
- Optional DNS action: decline leaves system untouched; confirmed execution logs success/failure, then rescans. A command failure must not leave an earlier successful result displayed as the latest attempt.
- Standard-worker and UAC paths remain unchanged. This release does not replace the managed Windows 11 remediation pilot or Authenticode signing requirement.
