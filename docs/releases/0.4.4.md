# 0.4.4 — Primary guidance and critical-first summary

The next Service Desk step comes from the primary finding's recommendation. A recommended action for a secondary problem no longer replaces it. If guidance is blank, the application asks for manual investigation before system changes instead of choosing an unrelated action.

The clipboard observation list uses the same stable severity/penalty order as triage: CRIT before WARN, then descending penalty, preserving source order for ties. The eight-observation limit is applied after sorting. Longer lists explicitly state how many observations were omitted and point to the complete HTML/JSON report.

No changes to diagnostics collection, assessment thresholds, score, remediation selection, elevated worker, IPC, or workflows. The existing list of allowed remediation actions is unchanged. Rendering guidance never starts an action.
