## Review correction

Set `EnsureLocatable = true` on the native Storage query options. The calculation of reliability counters depends on GetRelated from the original disk instance. Explicitly requiring locatable system properties avoids depending on a provider's incidental treatment of SELECT projections. This is a robustness correction, not a claim that the earlier integration proved counter accuracy or availability for every device.

The other four review tests retain a real projected WMI-path check, search of folders beyond the 2000-row display cap with full JSON export, fault-first disk presentation with null counters preserved, and explicit stopped/incomplete report status. Tests were not removed or relaxed.

Primary implementation reference: https://source.dot.net/System.Management/System/Management/ManagementOptions.cs.html (EnumerationOptions.EnsureLocatable). The property requests __PATH/__RELPATH/__SERVER for query results; native enumeration behavior is documented separately.
