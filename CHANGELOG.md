# Changelog

## 0.3.5 — Service Desk UX and Releases

Изменения по результатам первого запуска 0.3.4 на реальном Windows 11 ПК:

- `CleanTemp` всегда присутствует в списке действий; автоматически рекомендуется и выбирается только при недостатке места на системном диске.
- `Применить выбранное` активно только при выборе хотя бы одного автоматизируемого действия и показывает количество выбранных действий.
- ручные рекомендации имеют недоступный checkbox и не могут ошибочно восприниматься как автоматически исполняемые.
- PID, CPU, RAM и I/O во вкладке процессов сортируются по числовому значению, а не по текстовой строке с единицами измерения.
- Event ID и количество событий сортируются как числа; timestamp — как дата/время.
- `START-HERE.txt` pilot-пакета записывается как UTF-8 BOM; CI проверяет корректное чтение русских строк.
- добавлен workflow `Publish GitHub Release`: после зелёного main-build публикуются прямые `Gradient-PC-Health-Check.exe`, `.sha256` и отдельный optional pilot/E2E ZIP.
- версия приложения: `0.3.5`.

Security boundary 0.3.4 сохраняется: административные remediation разрешены только из точного канонического Program Files path; bootstrap из Downloads отключён.
