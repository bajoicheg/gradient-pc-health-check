# Gradient PC Health Check

Внутреннее Windows-приложение Service Desk для первичной диагностики жалоб **«компьютер сильно тормозит»** и безопасного применения выбранных remediation.

Текущая ветка разработки: **0.3.0**.

## Формат продукта

Для инженера это один GUI-файл: `Gradient-PC-Health-Check.exe`. PowerShell/BAT/CLI для обычной работы не нужны. Тот же EXE имеет скрытый worker-режим только для UAC elevation выбранных административных действий.

## Сценарий Service Desk

1. Запустить EXE — диагностика стартует автоматически.
2. Оценить Health Score, CPU/RAM/диск/uptime, TOP процессов, события Windows и системные сведения.
3. На вкладке **Рекомендации** отметить галочками только нужные автоматизируемые действия.
4. Нажать **Применить выбранное**.
5. Если действие требует прав администратора, приложение вызывает стандартный UAC для второго экземпляра того же EXE.
6. После remediation автоматически выполняется повторная диагностика.
7. Вкладка **До / после** и HTML/JSON/ZIP фиксируют эффект и ошибки выполнения.

## Автоматизируемые действия

- `CleanTemp` — удаляет только старые файлы из Temp интерактивного пользователя и системного Temp; Prefetch не затрагивается.
- `FlushDns` — только по решению инженера при сетевых/DNS-симптомах.
- `DISM /RestoreHealth` — только по решению инженера, не является универсальной «оптимизацией».
- `SFC /scannow` — только по решению инженера.

DISM и SFC не выбираются автоматически. Перезагрузка, работа с SMART, завершение процессов и отключение автозагрузки остаются ручными рекомендациями.

## Безопасность elevation

Elevated worker принимает только allow-list действий, проверяет аргументы и возвращает результат GUI через именованный pipe с одноразовым nonce. Для запуска UAC из standard-user GUI EXE должен находиться в доверенном каталоге `Program Files`, чтобы непривилегированный пользователь не мог подменить бинарник перед вводом админских учётных данных.

## Диагностика

Собираются, в частности:

- CPU, RAM, очередь/активность диска;
- свободное место;
- uptime и pending reboot;
- физические накопители/HealthStatus;
- TOP-10 CPU/RAM/I/O;
- Critical/Error из System и Application за 24 часа;
- автозагрузка;
- Windows Update/BITS;
- сетевые интерфейсы;
- SecurityCenter/Kaspersky, когда информация доступна.

Health Score — эвристика triage, а не доказательство исправности.

## Сборка

Цель: Windows 11 x64, .NET 8 WinForms, self-contained single-file EXE. GitHub Actions на `windows-latest` выполняет restore, build с warnings-as-errors, встроенный smoke self-test, `dotnet publish`, single-file gate и SHA-256.

Брендинг: щит с буквой **G** в стиле семейства G-switcher, с дополнительной линией health/pulse, чтобы продукты различались визуально.
